# NeXXUs — краткий бриф для инвестора

**Статус продукта:** Public Beta Candidate `v2.0.0-beta.1`  
**Суть:** суверенная нода децентрализованного хранения файлов с erasure coding и mesh-обменом между узлами.

---

## Проблема

Централизованное облако = единая точка отказа, цензуры и vendor lock-in.  
Классические DePIN-хранилища сложны в операциях и часто требуют тяжёлого токена/chain с первого дня.

## Решение

Лёгкий **node-first** стек:

- файл → 16 KB → RS(4+2) → CAS;
- передача по своему TCP-протоколу с аутентификацией;
- опциональное шифрование до записи на диск;
- анти-free-rider через репутацию и state channels (без обязательного L1 на beta).

## Что уже доказано технически

- 10 циклов независимого аудита с закрытием замечаний;
- работающие put/get/repair/mesh E2E тесты;
- честный реестр незавершённого (`[SIM]`: Tor, PQC, полный DHT…).

## Рынок (контекст)

DePIN storage (Filecoin, Arweave, Storj и др.) остаётся заметным сегментом инфраструктуры Web3/AI data. NeXXUs занимает нишу **контролируемой self-hosted mesh-ноды** и может расти в сторону провайдерской сети.

## Бизнес-модель (варианты post-beta)

1. ПО / support для операторов нод.  
2. Hosted «node-as-a-service».  
3. Позже — токен incentives (не требуется для beta).

## Конкурентные отличия на текущем этапе

- Прозрачность: симуляции не выдаются за production.  
- Короткий путь до работающего file+mesh без тяжёлого chain.  
- Аудируемый Rust-workspace.

## Риски

- Discovery/NAT для домашних нод.  
- Сивил-атаки на репутацию без stake.  
- Дорога к feature-parity с крупными DePIN.
