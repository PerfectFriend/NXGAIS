# NeXXUs — короткое руководство пользователя

Простыми словами: **NeXXUs — это программа, которая хранит ваши файлы кусочками на своём диске и может раздавать кусочки другим компьютерам в сети**, чтобы файл не пропал, если часть кусочков потеряется.

---

## Что нужно

- Компьютер с Linux (или среда, где собирается Rust-проект)
- Установленный `nexxusd` (сборка из репозитория или install-скрипт)

---

## 1. Запустить свою «ноду»

```bash
nexxusd serve --storage-dir ~/nexxus-data --p2p-bind 127.0.0.1:4000
```

Так нода слушает команды с этого же компьютера.  
Если нужно, чтобы **другие** машины присылали данные, укажите:

```bash
nexxusd serve --storage-dir ~/nexxus-data --p2p-bind 0.0.0.0:4000
```

и откройте порт **4000/tcp** в файрволе.

---

## 2. Положить файл

```bash
nexxusd put ~/Documents/photo.jpg --storage-dir ~/nexxus-data
```

Программа:

1. нарежет файл на кусочки;
2. сделает запасные копии кусочков (чтобы можно было восстановить при поломке);
3. сохранит всё на диск;
4. выдаст **номер-манифест** (длинная строка из букв и цифр).

**Сохраните этот номер** — по нему файл потом забирают.

### С шифрованием (рекомендуется для личных файлов)

```bash
echo "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef" > ~/nexxus-data/my.key
chmod 600 ~/nexxus-data/my.key
nexxusd put ~/Documents/photo.jpg -s ~/nexxus-data --key-file ~/nexxus-data/my.key
```

Без ключа потом файл не прочитать. Ключ не теряйте.

---

## 3. Забрать файл

```bash
nexxusd get НОМЕР_МАНИФЕСТА -o ~/restored.jpg --storage-dir ~/nexxus-data
```

С ключом:

```bash
nexxusd get НОМЕР_МАНИФЕСТА -o ~/restored.jpg -s ~/nexxus-data --key-file ~/nexxus-data/my.key
```

---

## 4. Два компьютера (кратко)

На компьютере B:

```bash
nexxusd serve -s ~/nexxus-data --p2p-bind 0.0.0.0:4000
```

На компьютере A:

```bash
nexxusd put ./file.bin -s ~/nexxus-data --peers IP_Б:4000
```

Если на A кусочки стёрлись:

```bash
nexxusd get МАНИФЕСТ -o ./file.bin -s ~/nexxus-data --peers IP_Б:4000
```

или починить локальные копии:

```bash
nexxusd repair МАНИФЕСТ -s ~/nexxus-data --peers IP_Б:4000
```

---

## 5. Полезные команды

| Команда | Зачем |
|---------|--------|
| `nexxusd status` | Состояние ноды (и список того, что ещё «учебное»/SIM) |
| `nexxusd peers` | Список известных пиров |
| `nexxusd challenge --all` | Проверка, что данные на месте |
| `nexxusd peer-dial --addr IP:4000` | Проверка связи с другой нодой |

---

## 6. Чего ждать не стоит в beta

- «Как Google Диск с сайтом» — это пока программа для терминала.
- Работа из-за сложного домашнего NAT без проброса порта.
- Полная анонимность как у Tor — транспорт Tor пока в режиме заготовки.
- «Сама себя чинит по всему интернету» — нужна связь с пирами, которых вы указали.

---

## 7. Если что-то не работает

1. Правильно ли указан `--storage-dir`?  
2. Совпадает ли ключ при `get` с ключом при `put`?  
3. Для сети: пингуется ли IP и открыт ли порт 4000?  
4. Посмотрите `nexxusd status` и текст ошибки в терминале.

Удачи. Номер манифеста и ключ — это и есть доступ к вашему файлу.
